# Default Repository Folder

This is the default local directory managed by the **Customizable Git Operations** toolkit.

- If you chose the default directory during setup, your project files and `.git` repository are located here.
- You can store, edit, and create code or files inside this directory.
- Running **`1_SAVE_FILES.bat`** (or Option `[1]` in `MENU.bat`) will stage, commit, and push changes from this folder to your connected GitHub repository.
- If you prefer to manage a folder in another location on your computer, you can reconfigure the path anytime using Option `[6]` in `MENU.bat` or by editing `storage\CONFIG.bat`.
